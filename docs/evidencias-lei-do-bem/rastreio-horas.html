4. Método, cargo e o que não entra

Como o C/H foi obtido

  • Dias com evidência densa no git (vários commits ou PR mergeado) = 8 h.
  • Dia com um único commit (25/08) = 4 h.
  • 12/08 entra pela data de docs/AUDITORIA.md.
  • Não se soma hora de Cursor Agent: o C/H é da pesquisadora que conduziu o ciclo (especificação, revisão, teste, merge).
